# NỌX
Global decentralized communication system focused on privacy, minimal data, and resistance to tracking.

## Core Principles
- No identification
- No logs or history
- No terms or payments
- Decentralized architecture
- Tracking protection at all levels

## Purpose
NỌX is designed for secure exchange of messages and data without reliance on central servers or intermediaries.

## Current Status
The project is under active development.
