# Security Policy

## Supported Versions
We maintain security updates only for the current stable release.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability
If you discover a security vulnerability in the NỌX system, please report it privately.

- Contact: security@noxsystem.net
- Do not disclose the vulnerability publicly until it has been fixed.
- Provide as many details as possible to help reproduce and address the issue.
